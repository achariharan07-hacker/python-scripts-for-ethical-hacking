# 🔍 Python Port Scanner

A simple, customizable port scanner written in Python.  
Built for ethical hacking labs, penetration testing practice, and network troubleshooting.

---

## ✨ Features
- Scan single or multiple ports on a target host
- Banner grabbing for service identification
- Multi-threaded scanning for faster results
- Clean and beginner-friendly codebase

---

## 📦 Setup
1. Download or copy the script into your working directory.
2. Ensure you have **Python 3.x** installed.
3. No external dependencies are required — only standard libraries (`socket`, `argparse`, `threading`).

---

Run the script with Python:
